# Problem Statement

The project aims to create a multiplayer number guessing game where players compete by guessing a randomly generated number between 1 and 100.

The game demonstrates Python concepts such as functions, loops, conditional statements, lists, random number generation, input validation, and sorting.

# Scope of the Project

The project includes:

* Multiple player registration.
* Random number generation.
* Turn-based guessing.
* Multiple rounds.
* Player scoring.
* Current and final scoreboards.
* Input validation.
* Player ranking.

The game is designed as a command-line application.

# Target Users

* Python beginners
* Programming students
* Students practicing Python
* People interested in simple multiplayer games

# High-Level Features

1. **Multi-Player Support** – Multiple players can participate.
2. **Number Guessing** – Players guess a number from 1–100.
3. **Hints** – Players receive higher/lower hints.
4. **Scoring** – Round winners receive points.
5. **Multiple Rounds** – Players can continue playing additional rounds.
6. **Scoreboard** – Displays current and final rankings.
7. **Input Validation** – Handles invalid user input.
