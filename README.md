# 🎯 Multi-Player Number Guessing Game

## Overview

A Python command-line game where multiple players take turns guessing a randomly generated number between 1 and 100. Players earn points by correctly guessing the secret number.

## Features

* 👥 **Multiple players:** Scales dynamically to handle turn-based guessing for any group size.
* 🎯 **Random number:** A new secret number between 1–100 is generated every round.
* 🔄 **Multiple rounds:** Keep the rivalry going as long as you want.
* 🏆 **Individual scoring system:** Tracks wins persistently across the session.
* 📊 **Current and final scoreboards:** Displays real-time standings and a sorted final ranking.
* ⬆️ **Directional hints:** Provides "too low" and "too high" feedback after every guess.
* ⚠️ **Input validation:** Catches letters, out-of-bound numbers, and blank inputs without crashing.

## Technologies / Tools

* **Python 3**
* **Random module** – Generates the secret number
* **Command-line interface (CLI)** – Used to interact with players

## Installation

1. Ensure you have **Python 3** installed on your system.
2. Download or clone the project files.
3. Open your terminal or command prompt and navigate to the project directory.

*Note: No external libraries are required.*

## Running the Project

Execute the following command in your terminal:

```bash
